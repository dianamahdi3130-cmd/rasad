# فحص الوصول إلى البيانات الحرارية الأصلية

يختبر هذا المسار الحساب المحفوظ في أسرار GitHub، دون تشغيل كاشف جديد أو إرسال تنبيهات. نجاحه يعني أن تنزيل ترويسة من ملف أصلي مسموح للحساب؛ لا يعني أن الملف الكامل عولج أو أن حريقاً تأكد.

أضف سرّين في إعدادات المستودع → Secrets and variables → Actions:

- `EUMETSAT_CONSUMER_KEY`
- `EUMETSAT_CONSUMER_SECRET`

بعد إضافة ملفات الفحص إلى الفرع `main`، يعمل مسار **رصد - فحص اتصال EUMETSAT** تلقائياً. ويمكن تشغيله من تبويب Actions ثم Run workflow. حفظ الأسرار وحده لا يشغّل اختباراً.

النتيجة العربية تظهر في Summary، ويمكن تنزيل `eumetsat-access-report`. التقرير لا يتضمن المفاتيح أو رمز الوصول أو أجسام استجابات الخادم. لا تُرفَع العينة الثنائية ضمن النتائج.

يبحث الفحص عن منتج HRFI من `EO:EUM:DAT:0665` بين ساعتين وثلاث ساعات قبل التنفيذ. يستخدم المصادقة الرسمية، ثم يستعلم عن منتج واحد ويقرأ حتى 64 بايت من ملف NetCDF واحد للتحقق من ترويسته. يطلب Range ولا يقرأ الملف كاملاً إذا تجاهل الخادم هذا الطلب. لا يطلب تغذية آنية أو يفعّل ترخيصاً مدفوعاً.

أهم النتائج:

| الحالة | المعنى |
| --- | --- |
| `raw_access_ok` | نجحت المصادقة وقراءة ترويسة بيانات أصلية؛ يلزم بعد ذلك تطوير المعالجة والتحقق العلمي. |
| `missing_credentials` | أحد السرّين غير متاح للمسار بالأسماء المحددة. |
| `authentication_failed` | لم تنجح المصادقة؛ راجع القيم وحالة الحساب. |
| `download_denied` | المصادقة نجحت والتنزيل رُفض؛ راجع صلاحية المجموعة والترخيص، دون افتراض أن الدفع مطلوب. |
| `no_products` | الاستعلام نجح ولكن نافذة البيانات كانت خالية. |
| `download_unavailable` | تعذر تنزيل العينة، ومنها HTTP404؛ لا يحدد ذلك وحده سبب التعذر. |
| `service_unavailable`, `network_error`, `timeout` | فشل اتصال أو خدمة؛ لا يثبت خطأ المفاتيح. |

المصدران الرسميان: [كتالوج HRFI](https://api.eumetsat.int/data/browse/1.0.0/collections/EO%3AEUM%3ADAT%3A0665?format=html)، و[عميل EUMDAC المرجعي](https://gitlab.eumetsat.int/eumetlab/data-services/eumdac).
