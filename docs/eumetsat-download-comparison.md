# مقارنة مساري تنزيل EUMETSAT

نجاح التنزيل اليدوي من Data Store مع رفض اختبار API لا يحدد السبب وحده. يختبر هذا المسار المصادقة نفسها، ويختار منتج HRFI أقدم من ساعتين، ثم يقارن مسارين للمنتج نفسه: ملف NetCDF داخل الأرشيف، والأرشيف الكامل.

لا يقرأ أكثر من64بايت من كل تنزيل ناجح، ويغلق الاستجابة حتى إن تجاهل الخادم Range. يقرأ حتى4كيلوبايت من جسم خطأ للتصنيف فقط؛ لا يطبع النص الأصلي أو ترويسات المصادقة أو روابط التنزيل الموقعة. ينتهي الفحص خلال120ثانية، ولا يجدد المفاتيح أو يلغي الرموز ولا يرسل تنبيهات.

النتيجة تظهر في مسار Actions باسم «رصد - مقارنة تنزيل EUMETSAT» وتُحفظ في ملف JSON:

- raw_access_ok: وصلت ترويسة HDF5/NetCDF من ملف منفرد.
- archive_only_access: وصلت ترويسة ZIP من الأرشيف؛ لم تثبت قراءة الملف المنفرد.
- api_download_denied: رفض الخادم المسارين برمز401أو403 بعد نجاح المصادقة.
- download_test_incomplete: لم تثبت مقارنة كاملة بسبب محتوى غير معروف أو خطأ اتصال أو خدمة.

تتضمن النتيجة معرّف المنتج العام واسم الملف وأوقات الرصد المعروفة، ومدة صلاحية الرمز كعدد ثوانٍ، دون الرمز نفسه. لا تثبت قراءة الترويسة إمكانية المعايرة أو أن حريقاً معيّناً موجود في البيانات. هذا الفحص منفصل عن كاشف رصد.
